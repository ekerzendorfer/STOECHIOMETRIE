# 🧪 STÖCHIOMETRIE-MEISTER PRO
### Digitales Chemie-Zentrum | Edition St. Pölten 2026

**STÖCHIOMETRIE-MEISTER PRO** ist eine hochpräzise, webbasierte Anwendung für den Chemieunterricht der Sekundarstufe 1 und 2. Sie kombiniert ein stöchiometrisches Rechenlabor mit einer interaktiven Trainingsumgebung, die Schülern nicht nur Ergebnisse liefert, sondern den kompletten chemischen Rechenweg transparent macht.

### 🚀 Quick Start
Einfach die `index.html` in einem beliebigen Browser öffnen. Es ist keine Internetverbindung für die Berechnungen erforderlich (Offline-Ready).
* **Erweiterbarkeit:** Die Stoff- und Reaktionsdatenbanken sind modular im Code hinterlegt und können leicht ergänzt werden.
---

## 🌟 Kern-Features

### 1. Intelligentes Reaktions-Labor
* **Echtzeit-Stöchiometrie:** Berechnung aller Massenbilanzen basierend auf einem einzigen Eingabewert.
* **Breites Spektrum:** Von einfachen Verbrennungen bis hin zu komplexen organischen Reaktionen (Neutralisation, Addition, Substitution, Veresterung).
* **Massenbilanz-Garantie:** Die Engine berechnet Stoffmengen ($n$) und Massen ($m$) präzise auf Basis der hinterlegten Molmassen (2-4 Dezimalstellen).

### 2. Interaktives Training & KI-Lösungsweg
* **Adaptives Üben:** Aufgaben werden dynamisch generiert (Sek 1: Molmassen-Fokus | Sek 2: Reaktions-Stöchiometrie).
* **Didaktischer Bonus:** Nach jeder Aufgabe wird ein detaillierter **Schritt-für-Schritt-Lösungsweg** eingeblendet ($m \to n \to \text{Verhältnis} \to m_{neu}$), der das Selbststudium massiv unterstützt.

### 3. Umfassende Datenbank
* **Erweiterte Organik:** 12 wichtige organische Verbindungen (von Methan über Ethanol bis zur Glucose).
* **IUPAC-Konformität:** Korrekte Notation von zweiatomigen Gasen ($H_2, N_2, O_2, Cl_2$) und Elementsymbolen ($MgO$ statt $MGO$).

### 4. Werkzeuge für Power-User
* **Optimierter Rechner:** Ein kompakter Taschenrechner mit Ziffernblock-Support und kontrastreicher Anzeige für schnelles Arbeiten während der Präsentation.
* **Sek 1 / Sek 2 Toggle:** Schnelles Umschalten des Schwierigkeitsgrades und der Aufgabenkomplexität.

---

## 🛠 Technische Details

* **Technologie:** Single-File HTML5 (keine Installation notwendig, läuft in jedem Browser).
* **Styling:** Tailwind CSS für ein modernes, responsives Interface (Beamer-optimiert).
* **Logic:** Vanilla JavaScript (Zero-Dependencies) für maximale Stabilität und Performance.

---

## 📖 Einsatz im Unterricht

1. **Demonstration:** Visualisierung von Massenänderungen bei chemischen Reaktionen im Plenum.
2. **Selbststudium:** Schüler nutzen den Trainingsmodus, um durch die eingeblendeten Lösungswege Fehler selbstständig zu erkennen.
3. **Leistungskontrolle:** Das MC-Quiz dient als schneller "Exit-Ticket"-Check am Ende einer Unterrichtseinheit.
